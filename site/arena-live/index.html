06 · How it's fair

Same inputs. Same clock. Seeds fixed in advance.

  • Same observation, same options

    Every model receives the same text observation and chooses from the same closed option list.

  • Simultaneous moves

    All players move at the same time. No model sees another's move before choosing its own.

  • Lockstep clock

    The game waits for every model, so network or hardware speed cannot decide the outcome. Latency is shown, not scored.

  • Seats rotate

    Starting positions rotate every round, so no model keeps a favourable seat.

  • Pinned vendors, one attempt

    Jev, OpenJev and Laya run through their published, pinned adapters with one attempt per decision.

  • Zero bad replies

    0 late, invalid or error replies for any model, across all decisions.

  • Videos are replays

    Every video is an exact replay of the logged decisions from the scored run.

  • Seeds pre-registered

    Seeds were fixed before play. The per-decision records archive is pinned by commit–reveal, sha256 of records_20260925.tar.gz:

07 · Read before quoting

What this does and doesn't show

  • An exhibition: 10 rounds per game, played on one day, 2026-09-25. It is not a universal ranking.
  • Every model received the same shared sensor features.
  • The Nagi lines differ in backbone family and training recipe, not only in size.
  • Arena Live measures skill under fixed, known rules. On our internal test of reading brand-new rules, the 27B line does not yet improve over the 12B line — that is our next research target.
  • The game engines and raw records stay private for now so the arena can keep working as a sealed benchmark; the archive hash above pins them.
